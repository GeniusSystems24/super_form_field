# Super Form Field example

A runnable gallery for `super_form_field` 1.11.0.9.0.

The app demonstrates all form fields plus the dropdown and popup-menu controls with the unified `InputDecoration` API,
GeniusLink `super_core` section components and `SuperAppBar`, light/dark themes,
LTR/RTL layouts,
validation submit sweeps, numeric stepping, mobile/desktop date interactions,
range-date selection with two calendars, fixed boundaries, bounds, and configurable presets,
dedicated masked phone-input and OTP-input screens, and ERP-oriented sample data.

## Run

```bash
flutter pub get
flutter run
```

Use the gallery toolbar to switch theme and text direction. Open each demo to
inspect basic, controlled, validated, disabled, read-only, and bilingual cases.
